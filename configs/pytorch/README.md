# PyTorch environment

The author-supplied export records Python 3.8.20 and PyTorch 1.12.1 on Windows. PyTorch was built with CUDA 11.3; no CUDA device was visible when the export was collected.

`pytorch_environment.txt` contains the framework report. `requirements_record.txt` preserves the package export, including platform-specific build paths. It is an environment record, not a portable installation file. Set data and checkpoint paths separately when running the code.
